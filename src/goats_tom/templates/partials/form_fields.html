{% comment %} Renders form fields with Bootstrap 5 spacing. Needed where the form comes from TOMToolkit: its pages render through django-bootstrap4, whose ``form-group`` was dropped in Bootstrap 5, so the fields come out with no spacing at all. Takes ``fields``, an iterable of bound fields, and optionally ``note_for`` and ``note`` to hang one extra hint off the named field, ``hide_help_for`` to hide the help text of one field from sight, or ``mark_required`` to put an asterisk after the label of each required field. Help and errors carry the ids Django's ``aria-describedby`` points at, so screen readers read them out. A multiple choice field with nothing to choose, such as groups when there are none, is left out. {% endcomment %} {% load custom_filters %} {% for field in fields %} {% if not field.field.widget.allow_multiple_selected or field.field.choices %}
