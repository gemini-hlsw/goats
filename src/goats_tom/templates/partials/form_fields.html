{% comment %} Renders form fields with Bootstrap 5 spacing. Needed where the form comes from TOMToolkit: its pages render through django-bootstrap4, whose ``form-group`` was dropped in Bootstrap 5, so the fields come out with no spacing at all. Takes ``fields``, an iterable of bound fields, and optionally ``note_for`` and ``note`` to hang one extra hint off the named field, or ``hide_help_for`` to drop the help text of one field. {% endcomment %} {% load custom_filters %} {% for field in fields %}
{% if field.field.widget.input_type == "checkbox" %} {% if field.field.choices %} {% for choice in field|with_widget_class:"form-check-input" %}
{{ choice.tag }}
{% endfor %} {% else %}
{{ field|add_class:"form-check-input" }}
{% endif %} {% else %} {{ field|add_class:"form-control" }} {% endif %} {% if note_for and field.name == note_for %}
{{ note }}
{% endif %} {% if field.help_text and field.name != hide_help_for %}
{{ field.help_text|safe }}
{% endif %} {% for error in field.errors %}
{{ error }}
{% endfor %}
{% endfor %}
